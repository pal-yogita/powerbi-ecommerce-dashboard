Accident Data Analysis Dashboard

An interactive Power BI dashboard designed to analyze road accident patterns, identify causes, and assist policymakers in improving road safety and accident prevention strategies.

This project transforms raw accident data into meaningful visual insights using ETL processing, DAX measures, and data modeling.

📌 Project Overview

The dashboard helps answer key questions like:

What is the total number of accidents, fatalities, and injuries?

Which locations have the highest accident rates?

What are the major causes of accidents?

Which vehicles are most frequently involved?

At what time of day or year do accidents peak?

How severe are most accidents?
